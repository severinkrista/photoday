# Итоги дня — проектирование функции

## Цель
Отдельный сценарий мобильного приложения PhotoDay для голосовой рефлексии. Он не меняет существующий журнал задач и его Excel-хранилище.

## Сценарий
1. На главном экране — заметная кнопка с микрофоном «Итоги дня».
2. При открытии приложение читает список вопросов из папки `Итоги дня` в том же каталоге Яндекс Диска, где расположен `photoday.xlsx`. Если список недоступен, показать сохранённый встроенный набор и объяснить, что список не удалось обновить.
3. На экране показывать один вопрос очень крупным шрифтом. Водителю не следует взаимодействовать с экраном во время движения: начинать и переключать ответы нужно только безопасно остановившись; голосовое управление можно добавить отдельно.
4. Нажатие на микрофон запускает запись текущего ответа. Повторное нажатие останавливает запись. Файл сразу сохраняется локально; переход к следующему вопросу не удаляет запись.
5. Можно пропускать вопросы и возвращаться к ним. Экран показывает прогресс и состояние ответа: нет записи / записан / запись идёт.
6. Кнопка «Отправить» доступна, даже если ответы есть только на часть вопросов. Перед отправкой показывается количество записей.
7. После подтверждения создаётся каталог `Итоги дня/ГГГГ.ММ.ДД` рядом с `photoday.xlsx`. Для каждого отвеченного вопроса загружаются два текстовых файла: `NN — Короткое название — вопрос.txt` и `NN — Короткое название — ответ.txt`. Голосовой файл ответа тоже загружается: `NN — Короткое название — ответ.m4a`. Вопрос и ответ хранятся отдельно, чтобы их можно было читать и обрабатывать независимо.
8. Записи удаляются с устройства только после подтверждённого успешного завершения всех загрузок. При сетевой ошибке локальные файлы и очередь остаются, доступна повторная отправка. Повторная отправка не должна создавать дубли: проверять путь/перезаписывать только соответствующий файл.
9. Внутри `Итоги дня` файл `questions.json` — источник пользовательского списка. Поддержать UTF-8, порядок вопросов, стабильный id и короткое имя для безопасного имени файла. Папку с датой создавать автоматически.

## Техническое разделение
- `DailyReflectionScreen`: крупный текст вопроса, запись, навигация, прогресс и отправка.
- `DailyReflectionRecorder`: Android MediaRecorder, файлы в приватном каталоге приложения, состояние записи.
- `DailyReflectionRepository`: загрузка вопросов, сохранение черновика и локальной очереди, перечисление завершённых ответов.
- `YandexDiskDailyReflectionUploader`: создание каталогов и загрузка файлов через уже используемую в приложении авторизацию Яндекс Диска. Не создавать отдельную OAuth-сессию.
- `questions.json` должен читаться с Диска, но иметь локальный резервный набор. Нельзя считать пустой ответ успешной записью.

## Формат папки
```
<папка photoday.xlsx>/
  Итоги дня/
    questions.json
    2026.10.10/
      01 — Главный результат — вопрос.txt
      01 — Главный результат — ответ.txt
      01 — Главный результат — ответ.m4a
```

## Критерии приёмки
- Запись каждого ответа сохраняется до перехода к следующему вопросу.
- После закрытия/перезапуска приложения незавершённая сессия и локальные записи не теряются.
- Можно отправить только часть ответов.
- При отключённой сети отправка не удаляет локальные файлы.
- Повторная отправка завершает загрузку без дубликатов и потери записей.
- Тексты вопросов и ответов лежат рядом с аудио в папке нужной даты.
- Проверить разрешение микрофона, отказ в разрешении, прерывание звонком, нехватку места и ошибку загрузки.
