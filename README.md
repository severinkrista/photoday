# Фото дня — Android

Новая Android-версия приложения создаётся с нуля.

Старый Python/desktop-код и предыдущие прототипы Android-приложения не являются частью архитектуры этого проекта.

## Цели первой версии

- Android-приложение на Kotlin + Jetpack Compose.
- Источник данных — существующий photoday.xlsx на Яндекс Диске.
- Существующие строки Excel не изменяются при чтении.
- Авторизация в Яндексе будет добавлена отдельным этапом.
- По умолчанию отображаются записи за последние 2 дня.
- Количество дней будет настраиваться пользователем.

## Архитектурные принципы

UI не обращается напрямую к сети или Excel. Поток данных:

UI → ViewModel → domain → Repository → внешний источник.

Доменный слой не знает о Яндекс Диске, Android UI или конкретной библиотеке XLSX.

Локальные данные могут использоваться как временный кэш, но authoritative source остаётся XLSX на Яндекс Диске.

## Текущее состояние

Этот коммит содержит чистый Android-фундамент без реализации интеграции с Яндексом и Excel. Следующие изменения должны добавляться небольшими проверяемыми этапами.
